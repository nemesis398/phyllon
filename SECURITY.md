# Security policy

## Reporting a vulnerability

Report it privately. Do not open a public issue.

1. Use GitHub's
   [private vulnerability reporting](https://github.com/nemesis398/phyllon/security/advisories/new).
   This is the preferred channel.
2. If you cannot use GitHub, email `security@phyllon.de`.

Say which version you tested, what you did, and what happened. A short
reproduction helps more than a long description.

## What to expect

The maintainer answers every report within 14 days. That first answer says
whether the report is accepted, needs more information, or is not a
vulnerability, and why.

## Supported versions

Only the latest release gets fixes, until 1.0. Every release before 1.0 is a
pre-release, and a fix may need an upgrade to the newest minor version.

## Disclosure

Disclosure is coordinated. The fix and the advisory are published together, and
the advisory credits the reporter unless they decline. Please keep the details
private until then.
